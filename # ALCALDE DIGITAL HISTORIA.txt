# VARIABLES DE LA HISTORIA

Para programarlo, cada decisión puede modificar variables.

```text
confianza
informacion_verificada
convivencia
bienestar
participacion
desinformacion
conflictos
reputacion
```

Por ejemplo:

```text
VERIFICAR
→ informacion_verificada + 5
→ confianza + 3
→ desinformacion - 3
```

y:

```text
COMPARTIR_FAKE_NEWS
→ desinformacion + 5
→ confianza - 3
→ conflictos + 2
```

Esto hace que **la historia no tenga una respuesta única**.

La misma escena puede terminar de forma diferente dependiendo de lo que haya ocurrido anteriormente.

# VARIABLES OCULTAS

También podemos tener variables que el jugador no vea directamente:

```text
reputacion_jugador
credibilidad_periodista
influencia
numero_de_seguidores
publicaciones_verificadas
publicaciones_compartidas
rumores_generados
relaciones_afectadas
```

Estas variables serán especialmente útiles cuando implementemos los distintos roles.

# ADAPTACIÓN A LOS CUATRO ROLES

La misma historia puede variar dependiendo del personaje.

### CIUDADANO

Tiene decisiones centradas en:

> compartir, verificar, ignorar y reportar.

### PERIODISTA

Obtiene escenas adicionales de investigación.

### INFLUENCER

Sus publicaciones tienen mayor propagación.

### CANDIDATO

Recibe escenas relacionadas con reputación, propuestas y comunicación pública.

Los cuatro roles están contemplados por el laboratorio.

```text
├── id
├── texto
├── veracidad
├── tipo
├── impacto
├── autor
├── compartidos
├── reportes
└── estado
```

Por ejemplo:

```text
ID 105
Texto:
"El Colegio Central será cerrado después
de las elecciones."

Veracidad:
Falsa

Tipo:
Rumor

Impacto:
8

Estado:
Activa
```

Ese objeto se inserta en el BST.

Así, cuando el jugador selecciona **VERIFICAR**, el juego puede buscar la publicación mediante su ID; cuando selecciona **REPORTAR**, puede localizarla y retirarla; y el recorrido del árbol puede utilizarse para mostrar el historial de publicaciones. El laboratorio exige precisamente justificar el problema resuelto por el árbol, su variante, inserción, eliminación y recorrido.

# CONEXIÓN FUTURA CON EL GRAFO

Después, cada publicación podrá recorrer una red como:

```text
Ana
├── Luis
│   └── Carlos
├── Pedro
│   └── María
└── Sofía
```

Por eso una misma decisión tendrá consecuencias diferentes dependiendo de las relaciones existentes entre ciudadanos.

El laboratorio plantea precisamente utilizar el grafo social para representar estas relaciones y determinar cómo se propaga una publicación.
